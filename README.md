# Světlonoši web V1

Obsah:
- index.html — hlavní web Světlonošů
- alfons.html — nenápadná veřejná stránka k ALFONS Publisher pro TikTok app review
- privacy.html — Privacy Policy
- terms.html — Terms of Service
- styles.css — společný vzhled
- assets/alfons.png — ikona ALFONS Publisher

## Doporučené URL pro TikTok
Po publikaci na GitHub Pages:
- Web/Desktop URL: .../alfons.html
- Privacy Policy URL: .../privacy.html
- Terms of Service URL: .../terms.html

## GitHub Pages
Nahraj obsah tohoto ZIPu do kořene repozitáře a v GitHub:
Settings → Pages → Deploy from a branch → main / root.
